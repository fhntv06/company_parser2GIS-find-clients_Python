# Журнал изменений

## 0.3.0: этап 1 завершён
- Источники: Overture Maps (бесплатно, по городу и теме), 2GIS Places API, импорт CSV.
- UI: запуск по городу и теме, прогресс, база с фильтрами, задачи, экспорт CSV/JSONL.
- Очередь в SQLite: возобновление после остановки, повторы, защита от дублей.
- Проверка сайтов: браузерные заголовки, повторы при временных сбоях, причина отказа в `note`,
  статусы `ok` / `alive` / `protected` / `error` / `parked` / `redirect`.
- Нормализация: домены (в т. ч. `.рф`), телефоны `+7...`, отсев соцсетей и виджетов чатов.
- Команды: `ui`, `overture`, `run`, `import`, `export`, `stats`, `check`, `recheck`, `probe`, `retry-failed`.
- Документация в `docs/`, инструменты в `tools/` (диагностика сайта, спасение базы).
- Известные ограничения: расписаний, Playwright и прокси нет; дедупа организаций по телефону нет.
