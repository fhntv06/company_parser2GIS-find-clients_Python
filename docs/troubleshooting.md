# Типичные проблемы

| Симптом | Причина | Что делать |
|---|---|---|
| `pip: command not found` / `tmux: command not found` | на Windows нет такой команды | `python -m pip ...`; tmux не нужен, запускайте `python -m dgis ui` в отдельном окне |
| `ModuleNotFoundError: No module named 'yaml'` (или `httpx`, `fastapi`) | окружение не активировано, запущен глобальный Python | `.venv\Scripts\Activate.ps1`, при необходимости `python -m pip install -r requirements.txt` |
| `running scripts is disabled` | политика PowerShell | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| В UI: `{"detail":[{"type":"missing","loc":["query","request"]...` | устаревший `dgis/ui/app.py` (типы FastAPI импортированы внутри функции) | обновить проект до текущей версии |
| В 2GIS нет сайтов, `с сайтом: 0 из 10` | демо-ключ не отдаёт контакты | нужен тариф с контактами или другой источник (Overture) |
| `Length of parameter 'page_size' should be from 1 to 10` | у ключа максимум 10 | `page_size: 10` в `config.yaml` (по умолчанию) |
| Тесты падают: ссылки `link.2gis.ru` вместо сайтов | устаревший `sources/api2gis.py` | обновить проект до текущей версии |
| В выборке лишние места (`student_union` при поиске `dent`) | слишком короткая подстрока | использовать `dental,dentist`, сверить категории `--list-categories` |
| Сайт в браузере открывается, а в базе `http 0` или «не открылся» | таймаут, сайт не пускает бота, старый TLS, сбой DNS под нагрузкой | `python -m dgis check домен.ru` покажет причину; причины по всей базе: `python -m dgis stats`; подробная диагностика: `python tools/diagnose_site.py домен.ru`. Временные сбои система повторяет сама (до 3 попыток), затем `python -m dgis recheck` |
| Сайт «защищен от ботов» (403/429/503) | сайт жив, но не отдает страницу автоматическим запросам | пометка `protected`, в экспорт попадает со статусом `alive`; этап 2 может получить отказ, учитывайте |
| В базе сайт со статусом 200, но это заглушка | парковка домена хостером | фильтр «парковка домена» в UI, в экспорте `--status ok` её исключает; после обновления выполните `python -m dgis recheck` |
| `Область слишком большая` | рамка города больше 4 град² | выберите город, а не регион, или задайте `bbox` вручную |
| `Город не найден` | Nominatim не распознал название | уточните название или задайте `bbox` вручную |
| `Не найдена команда overturemaps` | пакет не установлен | `python -m pip install overturemaps` (есть в `requirements.txt`) |
| Overture долго «качает» | первый запуск города, данные берутся из облака | подождать, повторные запросы используют кэш `data/overture/` |
| `ResourceWarning: unclosed database` в тестах | тесты используют базу в памяти | безвредно |
| Задача `failed` | ошибка источника или сети | вкладка «Задачи» покажет причину; «Повторить упавшие» или `python -m dgis retry-failed` |
| Прервали работу | | `python -m dgis run --resume` (или просто `ui`): незавершённое продолжится |

Журнал: `logs/parser.log` (ключи и пароли в нём маскируются).
Если ничего не помогло: пришлите текст ошибки целиком и вывод `python --version`.
