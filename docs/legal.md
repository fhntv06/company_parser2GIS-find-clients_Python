# Юридические заметки

> Это ориентиры для проекта, а не юридическая консультация. Перед массовой рассылкой проконсультируйтесь с юристом.

## Данные и лицензии
- **Overture Maps**: CDLA-Permissive 2.0, использование разрешено, при публикации данных нужно указывать источник.
- **2GIS**: сбор данных с сайта 2gis.ru запрещён пользовательским соглашением. Данные через API используйте на условиях вашего тарифа и уточните у 2GIS, можно ли хранить их в собственной базе.
- **Яндекс Карты (API организаций)**: данные только для показа на карте Яндекса, базу строить нельзя.

## Первое касание с клиентом (этап 3)
- **38-ФЗ «О рекламе», ст. 18**: реклама по электронной почте, телефону и мессенджерам допустима только с предварительного согласия адресата. Адрес из справочника согласием не является, в том числе для B2B.
  Безопаснее начинать с формы обратной связи на сайте или звонка и вести индивидуальные письма по существу.
- Заводите реестр: откуда контакт, когда обращались, отказ или отписка. Отписавшихся исключайте навсегда.
- **Персональные данные**: контакты ИП это данные физического лица. Для юрлиц ограничений меньше, но указывайте источник и давайте возможность отказаться.
- В письмах не запугивайте штрафами: формулируйте как «выявлены признаки возможного несоответствия», окончательный вывод делает юрист или Роскомнадзор.

## Нагрузка на чужие сайты
Проверка доступности делает один запрос на домен с таймаутом 5 секунд и не обходит сайт. Не меняйте это на массовый обход без необходимости.
