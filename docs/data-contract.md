# Формат выгрузки для этапа 2

Выгрузка получается командой `python -m dgis export --format jsonl --out sites.jsonl --status alive`
или кнопками CSV / JSONL на вкладке «База». **Одна строка = один сайт (домен).**

## Поля

| Поле | Тип | Описание |
|---|---|---|
| `domain` | строка | домен без `www` (для `.рф` в юникоде), уникален |
| `url` | строка | `https://<домен>/` (для `.рф` в punycode) |
| `target_url` | строка | **что открывать при анализе**: конечный адрес, если сайт переехал на другой домен, иначе `url` |
| `business_names` | массив | названия организаций с этим сайтом (у сети их несколько) |
| `city`, `rubric` | строка | город (из запроса) и категория |
| `phones` | массив | телефоны в формате `+7XXXXXXXXXX`, без повторов |
| `http_status` | число | ответ сайта; `0` означает, что ответа не было (причина в `note`) |
| `final_url` | строка | куда привели редиректы |
| `note` | строка / null | `error:<причина>` (`timeout`, `dns`, `ssl`, `reset`, `connect`, `redirects`), `protected` (сайт жив, но не пускает бота: 401/403/429/503), `parked` (заглушка хостера), `redirect:<домен>` (ушёл на другой домен) или пусто |
| `scan_hint` | строка | `ok` или `protected` (сайт жив, но не пускает ботов) |
| `analysis_status` | строка | `new` → `submitted` → `done` / `blocked` / `failed` (меняется при отправке в этап 2, см. [integration.md](integration.md)) |

Пример строки:
```json
{"domain": "dantist-kazan.ru", "url": "https://dantist-kazan.ru/", "business_names": ["Стоматология \"Дантист\" Казань"],
 "city": "Казань", "rubric": "dental_clinic", "phones": ["+78432772222"], "http_status": 200,
 "final_url": "https://doctorpromo.ru/", "note": "redirect:doctorpromo.ru",
 "target_url": "https://doctorpromo.ru/", "analysis_status": "new"}
```

## Что означает `--status`

| Значение | Что попадает |
|---|---|
| `ok` | строго: ответ 2xx–3xx и не парковка домена |
| `alive` | `ok` плюс `protected`: сайт реально существует (**рекомендуется для этапа 2**; у `protected` анализатор может получить отказ) |
| `protected` | сайт жив, но не пускает автоматические запросы (401/403/429/503) |
| `error` | не открылся: причина в `note` (`error:timeout` и т. д.) |
| `bad` | `error` плюс ответы 404, 5xx и т. п. (без `protected`) |
| `parked` | страница-заглушка хостера |
| `redirect` | ушёл на другой домен |
| `unchecked` | проверка ещё не выполнена |

Фильтры `--city` и `--rubric` работают так же. Без `--status` выгружаются все сайты.

## Как этапу 2 читать данные

**Из файла:** построчно читайте JSONL и анализируйте `target_url`.

**Из базы** (SQLite `data/dgis.db`):
```sql
SELECT domain, url, COALESCE(NULLIF(final_url,''), url) AS target
FROM sites
WHERE analysis_status = 'new'
  AND (http_status BETWEEN 200 AND 399 OR note = 'protected')
  AND COALESCE(note,'') <> 'parked';
-- после анализа:
UPDATE sites SET analysis_status = 'analyzed' WHERE domain = ?;
```
Для редиректов на другой домен берите `final_url`: анализировать нужно тот сайт, который видит посетитель.

## Ограничения данных

- Один домен может принадлежать нескольким организациям (сеть), а одна организация иметь несколько доменов
  (так бывает: у двух записей одинаковый телефон). Дедуп организаций по телефону пока не делается.
- Строка не означает, что организация целевая: часть мест (лаборатории, диагностические центры) попадает по категории.
- `city` берётся из запроса, а не из адреса места: рамка города захватывает окрестности.
